# Фаза 3 — UI и экспорт

Зависит от фазы 2 (`app/engine/pipeline.py`).

## Цель

Streamlit-приложение поверх `build_recommendations()` + экспорт в xlsx,
совместимый по колонкам с 1С.

## Задачи

0. **Кэширование обязательно.** `load_all()` на реальных данных занимает
   ~21 с. Обернуть загрузку в `st.cache_data` (и расчёт — по параметрам),
   иначе каждое изменение виджета ждёт 21 с и демо не работает.
1. `app/ui/streamlit_app.py`:
   - выбор поставщика (IEK / SE / оба), опционально категории/SKU-фильтр;
   - поля для `lead_time_days` / `coverage_days` (дефолты из конфига,
     редактируемые);
   - кнопка «Рассчитать» → таблица рекомендаций, сгруппированная по
     поставщику, с колонками: Код 1С, Артикул, Наименование, Поставщик,
     Рекомендуемое количество, Срочность, Обоснование;
   - отдельный блок/вкладка «На проверку» — SKU без продаж за 12 мес.
     (`review_needed` из фазы 2);
   - кнопка экспорта в xlsx (`app/export.py`, `pandas.to_excel` +
     `openpyxl`): **отдельный лист на каждого поставщика** с колонками
     Код 1С, Артикул поставщика, Наименование, Ед., Количество — заголовок
     в первой строке, без объединённых ячеек и пустых строк сверху
     (под загрузку «Заказа поставщику» в 1С:УТ); плюс лист «Обоснование»
     со всеми строками, поставщиком, срочностью и текстом;
   - показывать дату среза данных (`AS_OF`) и значения сроков поставки
     с пометкой источника (IEK — из данных, SE — допущение);
   - **никакой отправки заказа поставщику** — только просмотр и экспорт
     локального файла (RULE.md п.9).
2. Срочность уже считается в фазе 2 (`order.py`) — здесь только
   отображение и сортировка (высокая сверху).
3. `app/main.py` или `run.sh`/инструкция в README — как запустить
   (`streamlit run app/ui/streamlit_app.py`).

## Критерии приёмки

- `streamlit run app/ui/streamlit_app.py` запускается без ошибок на
  реальных данных из `data/raw/`; повторный расчёт после смены параметра
  занимает секунды, а не ~21 с.
- Тест на `app/export.py`: в файле есть лист на каждого поставщика с
  нужными колонками в первой строке и лист «Обоснование».
- Экспортированный xlsx открывается и содержит все обязательные колонки
  из `.planning/REQUIREMENTS.md`.
- Обновить `.planning/STATE.md`.
